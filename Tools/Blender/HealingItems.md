# Healing item model assets

- Editable Blender sources: `Tools/Blender/SourceModels/Healing/*.blend`.
- FBX exports and toon materials: `Assets/_Project/Models/Healing/`.
- Reusable visual prefabs: `Assets/_Project/Prefabs/Healing/Models/`.
- Existing pickup prefabs keep their original root components and GUIDs; the existing BoxCollider centre/size is fitted to the new mesh bounds for ground contact.
- Player prefab: the three saved `Held_*` model instances share the existing weapon hand attachment. Their serialized references are on `PlayerWeaponController`; visibility follows its replicated equipped item ID.

Authoring uses metres, centre/grip pivots, applied mesh transforms, Blender Z-up and -Y front. FBX export uses -Z forward and Y up, matching the project's weapon export workflow. The tape's circular axis is vertical; the spray and oil container stand upright. Pickup and held offsets remain independently editable in Unity.

To explicitly regenerate the model files, run Blender in background with `--python Tools/Blender/create_healing_items.py`. This operates in a separate Blender process and does not alter the open Blender document.

`Couch Guys > Healing Items > Apply Blender Models` assigns FBX material remaps, replaces pickup visual children, installs missing saved hand visuals, and validates the references. It runs only when explicitly selected. Existing hand offsets and material customizations are preserved. No healing settings, shop entries, animations or effects are generated by this command.

`Couch Guys > Healing Items > Test Local Host` runs the existing gameplay/network integration probe, including the equipped visuals, drop and pickup loop. Results are written to `Temp/HealingItemPlayResults.txt`.
